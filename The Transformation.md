# [[The Transformation|Atomic Note: From Base to Noble Character]]

## Definition

**Transformation** — Progressive [[Character Development]] through [[The Virtue Network]] that [[Transforms]] [[Lower Man]] {{Character}} toward [[Noble Man]] {{Character}}. This is not [[Nature]] [[Change]] but [[Person]] [[Growth]] [[Through]] [[Virtue Practice]], [[Experience]], [[Grace]], [[Discipline]].

This [[Transformation]] [[Requires]] [[Willpower]], [[Time]], [[Reflection]]. [[Transformation]] [[Is]] [[Not]] [[Gift]] {{BUT}} [[Result]] [[Of]] [[Consistent]] [[Virtue Practice]]. [[Lower Man]] [[Becomes]] [[Noble Man]] [[When]] [[Virtues]] [[Become]] [[Habit]] [[Through]] [[Repeated]] [[Practice]].
